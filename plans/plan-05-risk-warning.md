# Plan 05 · F6 呆滞/超储预警模块

> 对应 PRD 3.6　|　里程碑：M2 核心引擎

## 1. 目标
自动识别呆滞、超储、临期风险物资，输出处置建议并分级推送。

## 2. 需求
- **自动识别**：
  - 长期无领用（阈值可配置，如 12 个月）
  - 超安全库存
  - 临期/质保期到期物资
- **输出**：呆滞清单 + 处置建议（内部调剂 / 对外处置 / 报废）
- **预警分级**：提示 / 警告 / 严重
- **推送**：站内 + IM

## 3. 技术方案
- 预警规则引擎：规则可配置（阈值、分级标准、适用物料范围）
- 识别任务夜间批量执行（接入任务调度）
- 预警结果入库，推送消息对接 IM 机器人适配层（Plan 08）与站内消息
- 处置建议规则：优先内部调剂（联动 Plan 04 调剂匹配）

## 4. 任务清单
- [x] 预警规则配置管理（阈值/分级/范围）
- [x] 呆滞识别算法（无领用时长、金额加权）
- [x] 超储识别（对比安全库存）
- [x] 临期/质保期识别（需质保期字段支持，接 Plan 01 数据模型）
- [x] 处置建议生成规则
- [x] 预警分级与去重（避免重复打扰）
- [x] 站内预警中心数据接口
- [x] IM 推送对接

## 5. 验收标准
- 预警阈值、分级标准可配置
- 预警可分级推送到站内与 IM
- 呆滞清单含处置建议，内部调剂建议可跳转利库调剂看板
