# Plan 01 · F1 数据集成模块（适配器架构）

> 对应 PRD 3.2　|　里程碑：M1 数据底座

## 1. 目标
打通 ERP/采购、EAM/工单、WMS/库存、Excel 补录、外部行情五类数据源，建立统一数据仓库，为预测与利库引擎提供高质量数据底座。

## 2. 需求

### 2.1 数据源
| 数据源 | 数据内容 |
|---|---|
| ERP/采购系统 | 历史采购订单、供应商、价格 |
| EAM/工单系统 | 维修工单领用记录 |
| WMS/库存系统 | 实时库存、出入库流水 |
| Excel 补录 | 标准模板导入（兜底） |
| 外部行情 | 大宗商品价格（铜/钢/电缆等） |

### 2.2 集成方式（适配器化，按甲方环境配置）
- 标准数据集成接口（API / WebService / 中间表 / 库表直连只读）可插拔
- Excel 标准模板导入兜底
- 提供标准数据模型定义 + 数据字典，实施时按甲方系统做字段映射（配置化，不改代码）

### 2.3 同步方式
- 定时同步（T+1，可配置增量/全量）
- 同步任务可监控、失败告警

### 2.4 数据治理
- 物料主数据清洗与归一（同一物料多编码合并）
- 异常值识别、缺失值处理

## 3. 技术方案
- Python ETL 管道，接入任务调度（Celery/APScheduler）
- 适配器基类 + 各数据源适配器实现，注册到适配器注册表
- 字段映射配置文件（YAML/JSON），按数据源维护
- 数据仓库建模：物料主数据表、采购订单表、领用流水表、库存快照表、行情价格表
