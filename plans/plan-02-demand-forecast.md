# Plan 02 · F2 需求预测模块（SKU × 仓库粒度）

> 对应 PRD 3.3　|　里程碑：M2 核心引擎

## 1. 目标
对每个 SKU × 仓库维度预测未来需求量，为利库引擎提供输入。

## 2. 需求
- **输入特征**：历史领用量（工单）、历史采购量、季节性、维修计划（如有）、物料分类
- **输出**：未来 1/3/6/12 个月分 SKU×仓库需求预测值 + 置信区间
- **消耗模式分类**：稳定消耗 / 偶发消耗 / 备件类（Croston 模型）
- **规模**：十万级 SKU 批量预测任务可在数小时内完成（夜间任务）

## 3. 技术方案
- 算法框架：**Nixtla StatsForecast / mlforecast + LightGBM**（GitHub 高星开源、工业界验证），备选 Darts
- 自动模型选择：AutoARIMA / ETS / LightGBM 集成等，按消耗模式分类路由
- 备件类偶发消耗采用 Croston/SBA 模型，输出置信区间而非点值
- 预测流水线：数据同步 → 特征工程 → 批量预测 → 回测评估 → 结果入库，全链路可监控
- 回测评估指标：MAPE / WAPE，按物料分类设定阈值

## 4. 任务清单
- [x] SKU 消耗模式分类器（稳定/偶发/备件）

- [x] 模型池接入（AutoARIMA/ETS/Croston/SBA/LightGBM）

- [x] 置信区间输出
- [x] 批量预测任务（夜间，十万级 SKU，数小时完成）

- [x] 流水线监控与告警

## 5. 验收标准

- 单 SKU 预测结果可在 Web 端查看历史曲线 + 预测区间并人工修正
