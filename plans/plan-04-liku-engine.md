# Plan 04 · F5 利库引擎（平衡利库核心）

> 对应 PRD 3.5　|　里程碑：M2 核心引擎

## 1. 目标
产品核心算法引擎：先利库、后采购。基于需求预测、库存、在途、最小包装计算采购建议与跨仓调剂方案。

## 2. 需求

### 2.1 采购建议计算逻辑
```
建议采购量 = ceil(max(0, 预测需求 + 安全库存 − 现有可用库存 − 在途量) / 最小包装) × 最小包装
```

### 2.2 调剂建议
- 跨仓库/跨组织库存调拨建议（A仓富余 → B仓缺口）
- 附运距/时效参考

### 2.3 采购建议清单
- 品类、数量（最小包装取整）
- 建议下单时机（联动价格择时，Plan 03）
- 参考价格区间
- 依据说明（每条建议可追溯计算依据）

## 3. 技术方案
- 纯确定性算法（不用 LLM 计算数值），Python 实现
- 输入：需求预测（Plan 02）、实时库存、在途量、最小包装规格、安全库存参数（可配置）
- 调剂匹配：缺口-富余匹配算法（考虑运距/时效/组织权限）
- 每条建议生成计算依据快照，供审计与 Web 展示
- 输出结构化建议清单，供 Web 审核、导出、推送
