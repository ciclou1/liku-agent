# Plan 00 · 项目总览

> 来源：PRD_平衡利库智能体.md v0.2（投标方案稿）　|　日期：2026-09-08

## 1. 项目说明
- **项目性质**：投标项目，目标用户/甲方未最终确定，方案按**通用化产品**设计
- **设计原则**：所有外部系统对接（ERP/EAM/WMS/IM/SSO）均通过**适配器层 + 配置化**实现，不绑定任何具体产品；实施时按甲方实际环境配置接入方式
- **适应性承诺**：同一产品基座，通过适配器与配置适配不同行业、不同系统环境

## 2. 产品定位
基于人工智能与大数据计算的**平衡利库智能体**：综合分析历史采购量、维修工单领用情况、采购最小包装规格、市场价格趋势，为企业的物资采购、库存调剂、呆滞处置提供智能决策建议，实现"先利库、后采购"的库存平衡目标，降低库存资金占用与采购成本。

## 3. 核心价值
- **降本**：通过库存调剂利库减少重复采购；通过价格择时降低采购单价
- **提效**：自动化需求预测替代人工经验报计划
- **控险**：呆滞/超储预警，减少资金沉淀；缺料预警，保障维修/生产

## 4. 名词解释
| 术语 | 说明 |
|---|---|
| 平衡利库 | 在下达采购前，优先用现有库存（含跨仓库调剂）满足需求 |
| SKU | 最小库存单位（物料编码 × 规格） |
| 最小包装 | 供应商供货的最小计量单位（如整箱、整卷），采购量须为其整数倍 |
| 呆滞物资 | 长时间（可配置阈值，如 12 个月）无领用动的库存 |

## 5. 目标用户（通用角色模型，适配各行业甲方）
| 角色 | 核心诉求 |
|---|---|
| 采购员/物资计划员 | 快速生成科学的采购建议清单，避免拍脑袋报计划 |
| 采购/物资部门管理者 | 审批采购方案，查看降本金额、库存周转率 |
| 维修/生产一线人员 | 快速查询"哪里有货"、提交领用需求 |
| 公司管理层 | 查看库存健康度大屏、降本指标 |

## 6. 典型用户故事
1. 采购员小王：每月编制采购计划时，让智能体自动生成"建议采购清单"，每条建议附有依据（预测需求 − 现有可用库存 − 在途 + 安全库存，并按最小包装取整）。
2. 库管老李：智能体提示"3 号仓积压电缆 500 米，1 号仓下月需求 800 米，建议调拨"，一键发起调拨流程。
3. 管理者张总：月初查看大屏，看到本月因利库节约采购金额 XX 万元，呆滞物资清单及处置建议。
4. 一线维修工：在 IM 机器人中问"M12 螺栓哪个仓库有现货？"，秒级回复。

## 9. 全局设计原则（所有子计划共同遵守）
1. **算法与 LLM 职责分离**：数值预测、利库计算全部由确定性算法完成；LLM 只负责自然语言交互、结果解释、报告生成——保证数值可审计、防幻觉。
2. **适配器 + 配置化**：外部系统对接不绑定具体产品，实施按甲方环境配置。
3. **一期全功能交付**：各模块一期全部交付，规模按十万级 SKU 设计。
