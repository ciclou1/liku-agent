# Plan 06 · F7 对话式智能体（Chatbot）

> 对应 PRD 3.7　|　里程碑：M3 用户触点

## 1. 目标
自然语言问答入口，用户通过对话查询库存、生成建议、获取解释。

## 2. 需求
- **示例问答**：
  - "下个月电缆够不够用？"
  - "帮我生成本月采购建议"
  - "哪些物资呆滞超过一年了？"
  - "M12 螺栓哪个仓库有现货？"
- **防幻觉原则**：数值来自算法引擎（Text-to-SQL / Function Calling 受控查询），不来自 LLM 生成
- **可追溯**：回答附数据来源与依据说明

## 3. 技术方案
- LLM 网关抽象层（统一接口 + 路由策略：Claude API 云端 + 国产云端 API DeepSeek/通义，私有化模型 Qwen 预留）
- 受控查询：Function Calling 工具集（库存查询、预测查询、建议生成、预警查询等），不直接开放原始库
- Text-to-SQL 白名单模式（仅允许只读查询、表范围受限）
- 对话上下文管理、多轮会话
- 答案模板：数值 + 图表引用 + 数据来源说明

- 回答附数据来源与依据说明
- 数值类问题全部经由受控查询接口，审计日志可查
