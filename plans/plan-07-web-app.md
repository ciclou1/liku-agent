# Plan 07 · F8 Web 应用

> 对应 PRD 3.8　|　里程碑：M3 用户触点

## 1. 目标
独立 Web 应用，覆盖四类角色的核心工作场景。

## 2. 需求
- **角色门户**：采购员工作台 / 管理者看板 / 一线查询页
- **核心页面**：
  | 页面 | 内容 |
  |---|---|
  | 库存健康度大屏 | 周转率、资金占用、呆滞金额、降本金额 |
  | 采购建议清单页 | 生成 → 审核 → 导出/推送 流程 |
  | 利库调剂看板 | 调拨建议地图/列表 |
  | 预测详情页 | 单 SKU 历史曲线 + 预测区间，可人工修正 |
  | 价格趋势页 | 关键物料价格曲线与择时信号 |
  | 预警中心 | 分级预警列表与处置 |
- **权限**：按角色（RBAC）+ 数据范围（组织/仓库）
- 内置 Chatbot 对话窗口（Plan 06）

## 3. 技术方案
- React 18 + Ant Design 5 + ECharts
- 状态管理（如 zustand/Redux Toolkit）、React Router
- 与后端 FastAPI REST API 对接，登录走 SSO/内置账号（Plan 08 认证适配）
- 响应式布局，大屏页面适配投屏分辨率

## 5. 验收标准
- 四类角色各自门户可用，权限与数据范围隔离正确
- 采购建议全流程（生成→审核→导出/推送）可操作
- 大屏与各看板数据实时（查询 < 2s）
