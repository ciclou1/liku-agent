# Plan 03 · F4 价格预测与择时模块

> 对应 PRD 3.4　|　里程碑：M4 试点优化

## 1. 目标
预测关键物料价格走势，结合需求预测给出采购择时建议，降低采购单价。

## 2. 需求
- **数据**：自身历史采购价（多供应商报价）+ 外部大宗商品行情
- **输出**：
  - 关键物料价格趋势曲线
  - 未来 1-3 个月走势预测、涨跌信号
  - 择时建议："提前囤货 / 延迟采购 / 正常采购" + 预期节省金额
- **关键物料清单可配置**（并非所有 SKU 都做价格预测）

## 3. 技术方案
- 算法：Prophet / LightGBM + 行情特征（趋势 + 季节性建模）
- 行情数据通过抽象行情数据接口接入（支持不同行情服务商）
- 择时信号 = 价格走势方向 × 需求紧迫度 × 库存持有成本，规则引擎输出建议
- 预期节省金额 =（预测价格差 × 建议采购量），由确定性公式计算

- [x] 关键物料清单配置管理
